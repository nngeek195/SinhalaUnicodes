# SinhalaUnicodes

SinhalaUnicodes is a Sinhala typing and conversion project that helps users type in Singlish (English letters) and convert text into Sinhala Unicode, with support for legacy font output.

## Live Project & Download

- **Website:** https://sinhalaunicodes.vercel.app
- **Desktop EXE Download:** https://drive.google.com/file/d/15ekx8bo5uXdOuZ8T6h4YPwzjyV8S3viO/view?usp=sharing

## Project Overview

This repository contains multiple implementations of Sinhala typing tools:

- A **web-based converter** for instant Singlish-to-Sinhala conversion
- A **Windows desktop app** (WinForms) with real-time transliteration
- **Legacy project variants** that preserve earlier versions of the keyboard/converter workflow

The core idea is to make Sinhala typing easy for users who are more comfortable with Latin keyboard input.

## Key Features

- Real-time Singlish to Sinhala Unicode conversion
- Sinhala legacy font conversion support
- Copy-ready converted output
- Simple, lightweight interface for fast typing
- Multiple implementation variants for desktop and web usage

## Repository Structure

- `/web complete` – web application files (`index.html`, converter scripts, icon)
- `/KeyBoard` – main WinForms desktop project
- `/Full KeyBoard v1` – extended/older desktop variant
- `/KeyBoard with Legacy` – desktop variant with legacy-focused behavior

## Getting Started

### Option 1: Use Online

Open the live site and start typing:

https://sinhalaunicodes.vercel.app

### Option 2: Use Desktop EXE

Download the Windows executable:

https://drive.google.com/file/d/15ekx8bo5uXdOuZ8T6h4YPwzjyV8S3viO/view?usp=sharing

### Option 3: Run from Source

#### Web version
1. Open `/web complete/index.html` in a browser.

#### Desktop version
1. Open `/KeyBoard/KeyBoard.sln` in Visual Studio.
2. Build and run the WinForms project.

## Use Cases

- Typing Sinhala text quickly from a standard English keyboard
- Converting input to Unicode Sinhala for websites, documents, and messaging
- Generating legacy font-compatible Sinhala output where required
